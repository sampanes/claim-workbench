# Security Policy

## Supported Versions

Claim Workbench is currently pre-release. Security support begins with the first
tagged release.

## Reporting A Vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do
not include real patient, claim, credential, contract, or authentication data
in a report.

Include:

- affected component and revision
- reproducible steps using synthetic data
- expected and observed behavior
- potential impact
- a suggested mitigation, when available

## Sensitive Data

Public issues, pull requests, fixtures, screenshots, recordings, and logs must
use synthetic data. Reports containing sensitive information may be removed
from public view while they are investigated.
